# 🏦 Banking System

Este é um sistema bancário via terminal desenvolvido em **Python**, com foco na aplicação de conceitos de **Programação Orientada a Objetos (POO)**.

---

## 🎯 Propósito do Projeto

O objetivo deste projeto é praticar a estruturação de classes e métodos em Python simulando um sistema bancário com as seguintes funcionalidades:

- 👤 Criação de usuários  
- 🏦 Criação de contas bancárias para cada usuário  
- 💸 Realização de depósitos e saques  
- 📄 Emissão de extratos bancários

## ▶️ Como Executar

1. Clone este repositório:
```bash
git clone https://github.com/BrunOliveiraCA/banking_system.git
```
2. Acesse a pasta do projeto:
```bash
cd banking_system
```
3. Execute o script principal:
```bash
python main.py
```
